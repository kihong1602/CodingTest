# Problem 083

> BOJ 1947 선물 전달
> <br/>
> [링크](https://www.acmicpc.net/problem/1947)

## 문제

이번 대회에 참가한 모든 사람들은 선물을 하나씩 준비했다.

대회가 끝나고 난 후에 각자 선물을 전달하려고 할 때, 선물을 나누는 경우의 수를 구하는 문제다.

모든 사람은 선물을 하나씩 받으며, 자기의 선물을 자기가 받는 경우는 없다.

## 풀이

`완전 순열`의 개수를 구하는 문제로, 모든 사람이 자기 자신의 선물을 받지 않도록 배치하는 경우의 수를 계산하는 문제다.

`완전 순열`이란 N개의 원소가 있을 때, 어떠한 원소도 자기 자리에 위치하지 않는 순열이다.

초기 조건은 `dp[1] = 0`(한 사람은 자신의 선물을 받을 수 없다.), `dp[2] = 1`(두 사람은 서로의 선물을 교환하는 경우만 존재)이고,<br>
점화식은 `dp[i] = (i-1) * (dp [i-1] + dp [i-2])`이다.

범위가 크므로, 오버플로우 방지를 위해 각 연산마다 10^9로 모듈러 연산을 적용했다.

## 해결 전략

- `dp[1] = 0` `dp[2] = 1`로 기본값을 설정한다.
- 점화식`dp[i] = (i-1) * (dp[i-1] + dp[i-2])`로 경우의 수를 계산한다.
- 각 계산 단계에서 10^9로 나눠 오버플로우를 방지한다.
- 결과값인 `dp[n]`을 반환한다.
